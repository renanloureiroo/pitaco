# ADRs do Pitaco

Registros de decisão de arquitetura. Cada um descreve uma decisão tomada, o que
era verdade quando ela foi tomada e o que se aceitou pagar por ela.

**ADR não se atualiza.** Quando a decisão muda, escreva um novo que supere o
anterior e marque o antigo como `superado`. O valor de um ADR está em registrar o
que se sabia naquele dia — reescrevê-lo apaga exatamente isso.

Novo ADR: copie [`../templates/adr.md`](../templates/adr.md), use o próximo
número e nomeie o arquivo como `NNNN-titulo-em-kebab-case.md`.
